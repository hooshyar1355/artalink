پروژه اندروید: آرتا لینک پلنر (ver:4.14.3)
============================================

این پروژه همان محاسبه‌گر لینک وایرلس است که داخل یک WebView اندروید قرار گرفته (فایل برنامه: app/src/main/assets/index.html).
با Android Studio باز می‌کنید و فایل APK می‌سازید.

ساخت APK
--------
1) Android Studio (نسخه جدید) را نصب کنید و پوشه ArtaLinkPlanner را با File > Open باز کنید (نه پوشه app، خود پوشه اصلی).
2) صبر کنید Gradle Sync تمام شود. اگر Studio پیشنهاد کرد نسخه Gradle یا Android Gradle Plugin را به‌روز کند یا SDK لازم را نصب کند، قبول کنید (اینترنت لازم است).
3) APK آزمایشی (debug):
   Build > Build Bundle(s) / APK(s) > Build APK(s)
   فایل خروجی: app/build/outputs/apk/debug/app-debug.apk
   این فایل را روی گوشی کپی و نصب کنید (باید نصب از منبع ناشناخته را اجازه بدهید).
4) APK نهایی با امضا (برای توزیع):
   Build > Generate Signed Bundle / APK > APK > Create new... (ساخت keystore)
   فایل keystore و رمزها را حتماً جای امن نگه دارید؛ بدون آن نمی‌توانید نسخه‌های بعدی را روی همان برنامه به‌روز کنید.
   نوع Build را release بگذارید. خروجی: app/release/app-release.apk
5) برای اجرای مستقیم روی گوشی یا شبیه‌ساز: دکمه Run (مثلث سبز).

به‌روزرسانی برنامه بعد از تغییر صفحه
--------------------------------------
- فایل جدید fresnel-link-planner.html را با نام index.html در app/src/main/assets جایگزین کنید.
- در app/build.gradle.kts مقدار versionCode را بالاتر ببرید و versionName را عوض کنید (و در خود صفحه ver:4.14.3 را هم).

چیزهایی که در نسخه اندروید فعال است
----------------------------------
- دکمه GPS: برنامه اجازه مکان را می‌پرسد. صفحه از آدرس امن https://appassets.androidplatform.net/ بالا می‌آید، پس GPS درست کار می‌کند.
- شماره تلفن پایین صفحه: با لمس، صفحه شماره‌گیر گوشی باز می‌شود.
- دکمه خروجی KML: فایل را به صفحه «اشتراک‌گذاری» اندروید می‌دهد (Google Earth، Drive، پیام‌رسان‌ها، Files و...).
- لینک‌های بیرونی داخل برنامه باز نمی‌شوند و با مرورگر گوشی باز می‌شوند.

نکات مهم
--------
- برنامه برای نقشه، تصاویر ماهواره، ارتفاع زمین و کتابخانه نقشه (Leaflet از cdnjs) اینترنت لازم دارد. اگر این سرویس‌ها روی اینترنت گوشی بسته باشند (مثلاً بدون فیلترشکن)، نقشه یا ارتفاع نمی‌آید.
- برای وابسته نبودن به cdnjs، فایل‌های leaflet.js و leaflet.css (و عکس‌هایشان) را دانلود کنید، داخل app/src/main/assets بگذارید و آدرس آن‌ها را در index.html عوض کنید. این کار در سندباکس من ممکن نبود.
- این پروژه را من اینجا کامپایل نکردم (Android Studio و SDK در دسترس نبود). فقط فایل‌های XML و ساختار را بررسی کردم. اگر موقع Sync یا Build خطایی دیدید، متن کامل خطا را بفرستید تا درست کنم.
- نام بسته (applicationId): ir.artanetwork.linkplanner. برای عوض کردنش باید پوشه‌های java و namespace را هم عوض کنید؛ بهتر است همین بماند.
- حداقل نسخه اندروید: 7.0 (API 24).
- 3D روی گوشی‌های ضعیف ممکن است کندتر باشد؛ برای همین روی صفحه‌های لمسی شبکه زمین سبک‌تر ساخته می‌شود.
